# Chapter 01 – Python Programming Basics

This chapter contains Python programs demonstrating basic programming concepts and parallel computing.

The programs cover:

- **Classes:** Introduction to object-oriented programming.
- **Directories and Files:** Working with directories and file operations.
- **Flow Control:** Using conditional statements and loops.
- **Lists:** Working with Python lists.
- **Serial Processing:** Executing tasks sequentially.
- **Multithreading:** Running multiple threads concurrently.
- **Multiprocessing:** Executing tasks using multiple processes.
- **Threads and Processes:** Understanding their basic implementation.

**Purpose:** To understand Python fundamentals and the basics of serial, multithreaded, and multiprocessing execution.
